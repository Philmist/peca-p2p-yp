# Contract: 固定 >>1(スレ頭テンプレ)

**Feature**: 007-web-bbs-write | **参照**: [research.md](../research.md) R2/R3/R4、
[data-model.md](../data-model.md)

## 1. 板設定フィールド

| フィールド | 値 |
|-----------|-----|
| 名前 | `first_post_template` |
| 型 | string(プレーンテキスト。Markdown 解釈しない) |
| 既定 | `""`(未設定) |
| 設定経路 | `PUT /api/v1/livechat/threads/{board}/settings`(板主のみ・トークン必須) |
| 永続化 | SQLite `board_settings`(再起動後も保持) |
| 配布 | 006 の板設定配布と同経路。互換 API の SETTING.TXT には出さない |

## 2. 検証(FR-013)

kind 1311 レス本文の既存検証と**同一**(自動投稿が検証で落ちないことを構造的に保証):

- 最大 2048 文字・最大 32 行
- 制御文字は改行(LF)を除き除去(`sanitized()`)
- 上限超過は板設定検証エラー(既存の 400 系)— 保存されない
- 安全描画対象(表示時はテキストとしてエスケープ — FR-005)

## 3. 自動投稿の意味論(FR-014〜FR-019)

### 3.1 トリガ

| トリガ | 挙動 |
|--------|------|
| スレ開設(`open_thread`) | スレ生成直後、他のいかなる書き込みより先に >>1 を採番 |
| 次スレ移行(レス上限到達の自動移行 / 明示操作) | 新スレの >>1 に**その時点の**テンプレを自動投稿(FR-015/FR-017) |

### 3.2 投稿内容

| 項目 | 値 |
|------|-----|
| res_no | 1(必ず占有。res_limit にカウント・次スレ移行判定に含む — FR-019) |
| 本文 | `first_post_template`。空(未設定)なら**システム既定テンプレ**(§3.3) |
| 名前・メール | 空(表示は板の `noname_name`) |
| 署名 | 板鍵による kind 1311 署名(ホスト = 板主由来 — FR-016)。通常書き込みと同一の検証を満たす |
| PoW | 参加者向け初回 PoW(006 FR-017)を**課さない**(ホスト自身の採番) |
| 配布 | 通常の確定レス配布と同一(参加者側に特例なし。全端末で res_no=1 に一致 — FR-012) |

### 3.3 システム既定テンプレ(FR-018)

`first_post_template` が空の板では、以下の形式の最小テンプレで自動投稿する
(空 >>1 を生じさせない):

```text
{板タイトル} 実況スレ
対象チャンネル: {チャンネル名}
```

(正確な文言は実装で確定してよいが、板タイトルと対象チャンネルの案内を含み、
本文が空でないこと — MUST)

### 3.4 不変条件

- スレ開設完了後、そのスレの確定レス列に res_no=1 が**常に存在**する(`>>1` は開設直後
  から解決先を持つ — FR-014)
- テンプレ変更は変更後に開始するスレからのみ反映。確定済みスレの >>1 は不変
  (FR-017 / 006 FR-023)
- 参加者の最初の書き込みは res_no=2 以降になる

## 4. Gherkin シナリオ(Principle IV)

```gherkin
Feature: 固定 >>1 の自動投稿 (Principle I, II)

  Scenario: スレ開設で >>1 が自動確定する
    Given 板主が first_post_template を "配信URL: http://example/" と設定済み
    When 板主がスレを開設する
    Then res_no=1 がテンプレ本文で確定し全参加者に表示される
    And ">>1" アンカーは解決先を持つ

  Scenario: 次スレ移行でも >>1 が自動投稿される
    Given テンプレ設定済みの進行中スレがレス上限に到達した
    When 次スレへ自動移行する
    Then 新スレの res_no=1 に同じテンプレが自動投稿される

  Scenario: テンプレ変更は遡及しない
    Given テンプレ "旧" の >>1 を持つ確定済みスレが存在する
    When 板主がテンプレを "新" に変更し次スレを開始する
    Then 新スレの >>1 は "新"、既存スレの >>1 は "旧" のまま変わらない

  Scenario: 未設定の板でも空 >>1 にならない
    Given first_post_template が空の板
    When スレを開設する
    Then res_no=1 は板タイトルと対象チャンネルを含む既定テンプレで自動投稿される

  Scenario: 上限超過テンプレの拒否(ネガティブ)
    Given 板主が 2048 文字を超えるテンプレを設定しようとする
    When 板設定を適用する
    Then 板設定検証エラーで拒否され保存されない

  Scenario: 自動 >>1 は通常検証を満たす(ネガティブ観点)
    Given テンプレ設定済みの板
    When スレ開設で >>1 が自動投稿される
    Then その kind 1311 イベントは署名・サイズ・行数の通常検証に合格する
    And 参加者側は特例なく通常レスとして受理する

  Scenario: >>1 は res_limit にカウントされる
    Given res_limit=100 の板でスレを開設した(>>1 自動投稿済み)
    When 参加者が書き込みを続ける
    Then 100 番目のレスで上限に達し次スレ移行が判定される(>>1 を含めて 100)
```
