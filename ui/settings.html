設定

IPアドレス系の設定(pcp_bind / http_bind / p2p_bind / index_bind / compat_bbs_bind)の変更は再起動後に反映されます。 pcp_bind は loopback アドレス(127.0.0.1 等)のみ指定できます。 http_bind / compat_bbs_bind は loopback または LAN 内のプライベートアドレスを指定でき、 非 loopback 値(LAN 公開)を保存するときはリスク確認を求めます(確認で http_lan_consent / compat_bbs_lan_consent を有効化して保存します)。 p2p_bind はカンマ区切りで複数アドレスを指定でき、IPv4/IPv6 を同時に待ち受けられます (例: 0.0.0.0:7147,[::]:7147)。空文字にすると待受無効(外向き接続のみ)になります。 複数指定時、他ピアへ申告されるポートは先頭アドレスのポートのみのため、全アドレスで同一ポートの使用を推奨します。 index_bind は index.txt を LAN へ公開する場合のみ設定します(空文字=無効)。loopback または LAN 内の プライベートアドレスのみ指定でき、非 loopback 値の保存時にはリスク確認を求めます。

index.txt を LAN へ公開しようとしています。

掲載一覧(index.txt)が LAN 内で平文・無認証のまま配信され、 同じ LAN 上の第三者に取得・改ざんされうることを理解した上で有効化してください。

Web UI / JSON API(http_bind)を LAN へ公開しようとしています。

Web UI と JSON API が LAN 内で平文のまま読み書きに使われ、 セッショントークンも同じ LAN 上の端末に共有されうること(=実質的に LAN 内は誰でも 書き込み可能になりうること)を理解した上で有効化してください。

2ch 互換 API(compat_bbs_bind)を LAN へ公開しようとしています。

互換 API は無認証で、LAN 内の任意の端末(専ブラ等)が平文で 書き込み可能になります。信頼できる LAN 内でのみ有効化してください。
